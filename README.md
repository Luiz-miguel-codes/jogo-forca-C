# Jogo da Forca (C++)

Jogo da forca desenvolvido em C++, com sistema de dificuldade, dicas, pontuação e vidas.

## Funcionalidades

- 3 níveis de dificuldade (Fácil, Médio, Difícil), cada um com uma palavra e número de tentativas diferentes
- Sistema de dicas: revela uma letra em troca de 10 pontos
- Sistema de pontuação: ganha pontos ao acertar, perde pontos ao errar ou usar dicas
- Controle de vidas e tentativas
- Histórico de letras já tentadas
- Opção de jogar novamente ao final da partida

## Tecnologias utilizadas

- C++
- Bibliotecas: `iostream`, `string`, `locale.h`, `cctype`

## Como compilar e rodar

```bash
g++ forca.cpp -o forca
./forca
```
